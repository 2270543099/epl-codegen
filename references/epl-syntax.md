# 易语言源码语法速查（.e 文本格式）

本文件只覆盖「生成 / 修改 .e 源码」必需的部分。写出来的代码应能直接粘进易语言 IDE 的
代码编辑器并编译。

## 1. 编译单元骨架

```e
.版本 2

.程序集 窗口程序集_启动窗口
.程序集变量 模块编号, 整数型

.子程序 __启动窗口_创建完毕
.局部变量 子程序数据, 字节集, , "0"

加入成员 (子程序数据, 生成子程序数据 (“_启动子程序”, #启动子程序, , #整数型值))
写到文件 (取运行目录 () ＋ “\wnxd_macro.e”, 生成扩展模块数据 (子程序数据))
```

要点：

- `.版本 2` 必须是第一行，前面不能有空行或注释。
- 一个 `.e` 可以有多个 `.程序集`；子程序必须写在某个程序集里。
- 声明行顶格写，块体缩进 4 个空格（IDE 会用制表符，文本格式两者都能读）。

## 2. 声明行

| 声明 | 形式 | 说明 |
|---|---|---|
| 程序集 | `.程序集 名称` | |
| 程序集变量 | `.程序集变量 名称, 类型` | 可加数组标记，写法同局部变量 |
| 子程序 | `.子程序 名称, 返回类型` | 无返回值时写 `.子程序 名称` |
| 参数 | `.参数 名称, 类型, 修饰` | 修饰可省略，可组合：`可空`、`参考`、`传址`、`参考 数组`、`可空 数组` |
| 局部变量 | `.局部变量 名称, 类型, 静态, 数组维数, 备注` | 后三段可省略 |
| 常量 | `.常量 名称, "值"` | 程序集常量，引用时写 `#名称` |
| 全局变量 | `.全局变量 名称, 类型` | 模块级 |
| 数据类型 | `.数据类型 名称` + `.成员 名称, 类型` | 自定义结构 |
| DLL 命令 | `.DLL命令 名称, 返回类型, "DLL名", "函数名"` + 若干 `.参数` | 见下 |

DLL 命令示例（`传址` 表示取变量地址传入）：

```e
.DLL命令 RtlMoveMemory_整数, , , "RtlMoveMemory"
    .参数 Dest, 整数型, 传址
    .参数 Src, 整数型
    .参数 Length, 整数型
```

> 警告：`传址` 只作用于该参数本身。上例里 `Src` 没有 `传址`，所以实参 0 会作为
> **地址 0** 传进去（NULL），不是「指向 0 的指针」。这是原工程崩溃的根因，详见
> `templates.md`。

数组局部变量在 IDE 里显示为：

```e
.局部变量 分割代码, 文本型, , "0"      ' 第 3 段空 = 非静态；第 4 段 "0" = 动态一维数组
.局部变量 数组维数, 整数型, , "0"
```

多维写 `"0,0"`。本工程的 `生成局部变量数据` 按「第 3 段 = 静态标记、第 4 段 = 数组维数、
其后为备注」解析，改代码时以它为准。

## 3. 语句与表达式

```e
变量 ＝ 值                                  ' 赋值
命令 (实参, 实参)                            ' 命令调用，命令名与括号之间一个空格
无参命令 ()                                  ' 无参也要写括号
数组 [下标]                                  ' 数组下标从 1 开始
对象.成员                                    ' 成员访问
#常量名                                      ' 引用常量
“文本”                                       ' 字符串用全角引号
' 注释                                       ' 单引号注释到行尾
```

- 字符串拼接用 `＋`（全角加号）。
- 字节集字面量：`{ 0, 0, 1, 9, 48, 0, 0, 0 }`，元素取 0–255。
- 字节集可以按下标赋值：`b [1] ＝ 255`。

## 4. 流程控制

| 块首 | 中间 | 块尾 |
|---|---|---|
| `.如果 (条件)` | `.否则` | `.如果结束` |
| `.如果真 (条件)` | — | `.如果真结束` |
| `.判断开始 (表达式)` | `.判断 (值)` / `.默认` | `.判断结束` |
| `.判断循环首 (条件)` | — | `.判断循环尾 ()` （先判断后循环） |
| `.循环判断首 ()` | — | `.循环判断尾 (条件)` （先循环后判断） |
| `.计次循环首 (次数, 变量)` | — | `.计次循环尾 ()` |
| `.变量循环首 (起始, 终止, 步长, 变量)` | — | `.变量循环尾 ()` |

循环体内跳转：

- `.到循环尾 ()` —— 相当于 continue。
- `.跳出循环 ()` —— 相当于 break。**注意：它跳出的是最内层循环，不是「结束当前变量」；
  在处理变量数组时误用它，会把后面所有变量一起丢掉。**

## 5. 运算符

- 比较：`＝` `≠` `＞` `＜` `≥` `≤`
- 算术：`＋` `－` `×` `÷` `％`
- 逻辑：`且` `或` `非`
- 位运算（命令，不是符号）：`位与`、`位或`、`位异或`、`左移`、`右移`

## 6. 常用核心命令

| 类别 | 命令 |
|---|---|
| 文本 | `取文本长度` `取文本左边` `取文本右边` `取文本中间` `寻找文本` `倒找文本` `删首尾空` `子文本替换` `分割文本` `取文本` `到文本` `到整数` |
| 数组 | `取数组成员数` `加入成员` `删除成员` `插入成员` `清除数组` `重定义数组` `数组排序` |
| 字节集 | `取字节集长度` `取字节集左边` `取字节集右边` `取字节集中间` `字节集替换` `取字节集数据` `到字节集` `取空白字节集` |
| 文件 | `写到文件` `读入文件` `取运行目录` `文件是否存在` |
| 其它 | `是否为空` `选择` `取变量地址` `取变量数据地址` |

**基址规则（最容易错）**：`取字节集中间`、`取字节集左边`、`取字节集右边`、`字节集替换`、
`取文本中间`、`数组下标` 全部是 **1 基**；`取字节集数据 (字节集, 类型, 起始位置)` 的第三个
参数建议省略（默认从头读），避免 0/1 基歧义。

## 8. 常见编译/运行错误对照

| 现象 | 原因 | 修法 |
|---|---|---|
| 语法错误，指向某行中间 | 全角/半角混用（例如把 `,` 写成 `，`、把 `“` 写成 `"`） | 统一：字符串 `“”`，运算符全角，分隔符半角 |
| 不能将「文本型」转换为「整数型」 | 把文本参数直接当数字用 | `到整数 (...)`，并考虑失败为 0 |
| 数组成员引用下标超出范围 | 数组 0 基思维 | 下标从 1 起，先 `取数组成员数` 判空 |
| 访问无效内存 | 裸指针写错（`传址` 用法、地址为 0、地址来自未初始化变量） | 改成字节集切片/`字节集替换` |
| 变量被提前清零 / 结果少一半 | 循环里误用 `跳出循环` | 改 `.到循环尾 ()` |
